# 已实现功能

截至 v1.14.3。NeoDesk 只做控制端（Android，arm64），被控端运行普通 RustDesk。

## 设备与连接

- 输入设备 ID 连接，或扫描二维码填入 ID。
- 设备页：收藏（横向卡片）、最近连接、局域网设备。
- 设备菜单：远程控制、文件传输、终端、加入/移出收藏、重命名（别名）、删除。删除会同时从最近、收藏、局域网中移除，并立即生效。
- 在线状态：ID 设备向 ID 服务器查询；IP 直连设备用 TCP 探测；每 15 秒刷新。
- 意外断线后自动重连，最多 5 次，间隔逐次加长；重连界面可取消。
- 断开前确认（可关闭）。

## 两种操作模式

- **指针模式**：整个屏幕是相对触控板，拖动移动光标，手势点击。
- **触摸模式**：点哪里就点击哪里，光标默认隐藏。
- 新会话的默认模式可在设置中选择，会话中可随时切换。

## 手势

- 自研手势状态机，按手指数量识别，没有手势竞技场带来的延迟。
- 可识别：单指点按/长按/拖动，双指点按/长按/横向拖动/纵向拖动/捏合，三指点按，四指点按。
- 默认绑定：

  | 手势 | 触摸模式 | 指针模式 |
  |---|---|---|
  | 单指点按 | 左键 | 左键 |
  | 单指长按 | 按住左键（长按拖动：选择、拖拽） | 同左 |
  | 单指拖动 | 平移画面（画面未放大时移动光标） | 移动光标 |
  | 双指点按 | 右键 | 右键 |
  | 双指长按 | 按住右键 | 按住右键 |
  | 双指纵向拖动 | 滚轮 | 滚轮 |
  | 双指横向拖动 | 无 | 平移画面 |
  | 双指捏合 | 缩放（不可改） | 缩放（不可改） |
  | 三指点按 | 显示工具栏 | 显示工具栏 |

- 自定义手势：每个手势可在允许的动作中重新绑定（左/右/中键、双击、按住某键、显示工具栏、切换键盘、Esc、移动光标、平移、滚轮）。
- 手势灵敏度：长按时长、拖动阈值、点按阈值、捏合阈值、多指等待窗口、抬起即触发，带实时测试区。
- 长按拖动到屏幕边缘时继续滚动画面，便于跨屏选择。
- 指针模式下光标靠近边缘时自动平移画面，速度可调。
- 应用内手势说明。

## 画面

- 缩放（上限可调）、平移，工具栏一键「适应屏幕」与「1:1」。
- 旋转屏幕后自动重新适配；会话全屏沉浸，隐藏系统栏。
- 多显示器切换。
- 画质：最佳 / 平衡 / 低 / 自定义（画质百分比与帧率上限）。
- 编解码器选择（按对端支持过滤），桌面对端可改分辨率。
- 质量监视器：简洁（FPS、延迟）或详细（另含码率、网速、编解码器）。

## 键盘与按键

- 系统键盘：隐形捕获手机输入法并转为按键，支持中文等输入法整词提交。
- 特殊键面板：Ctrl/Alt/Shift/Win、Esc、Tab、Enter、方向键、F1–F12 等；支持「按住」以组合多个键。
- 组合键面板：自定义快捷键组合，可增删改排序。
- 鼠标按键面板（可在设置中关闭）。
- 键盘外观：按键大小、面板透明度、紧凑布局、宽按键。
- 音量键：音量加、减键可分别绑定为滚轮上/下、左键、右键、Ctrl/Shift/Alt/Win 或某个按键；短按为点击，长按为按住（滚轮则连续滚动）。滚轮方向与「反转滚动方向」无关。
- 辅助滚动条：右侧上下拉动滚动。滚动速度和反转开关作用于双指滚动与滚动条。

## 会话内工具

- 顶部状态栏与底部工具栏，可隐藏；隐藏后由可拖动的悬浮球唤回。
- 更多菜单：显示器、画质、编解码器、分辨率；同步剪贴板、播放远程声音、仅观看、跟随远程光标、阻止对端输入（需对端授权）、质量监视器、滚动条；锁定远程屏幕；画中画；Android 对端的返回键、主页键；断开连接。
- 画中画小窗：手动进入，或在后台时自动进入。

## 文件传输

- 本机 / 远程两个标签页，可浏览目录，远程可列出所有驱动器。
- 上传、下载、新建文件夹、重命名、删除，显示隐藏文件。
- 多选后批量传输或删除。
- 传输任务条：进度、速度、取消，被中断的任务可续传。

## 远程终端

- xterm 终端，字号可调并会记住，带 Esc/Tab/Ctrl 组合/方向键/Home/End/翻页等快捷键栏。

## 应用

- 深色 / 浅色 / 跟随系统主题；引擎弹窗同步主题。
- 界面语言：英文、中文、日文；引擎弹窗语言单独跟随设置。
- 全局字体大小。
- 应用锁：启动时要求生物识别或锁屏密码，开启时防截屏、在最近任务中隐藏内容。
- 应用内更新：从 GitHub Releases 检查新版，下载后调用系统安装器；失败时改为打开浏览器。

## 工程

- `rustdesk/` 由脚本从上游、补丁、覆盖层生成，引擎直接取自官方 APK，无需 Rust 工具链。
- 同步时校验引擎 sha256 与桥接符号。
- 单元测试覆盖手势状态机、双指分类、输入法差分、设备列表、滚轮方向。
