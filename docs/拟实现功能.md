# 拟实现功能

尚未实现、已知受限或需要验证的事项。完成一项后，把它移到 [已实现功能](已实现功能.md)。

## 功能

- **自定义服务器**：设置中可填写 ID 服务器、中继服务器、API 服务器和 Key。目前完全没有入口，只能使用 RustDesk 公共服务器。
- **多会话**：同时控制多台设备，或在控制时同时传文件。远程控制和文件传输共用一个全局 `gFFI`，同时打开会互相冲突；终端已用独立的 FFI 绕开了这个问题，可作参考。
- **多标签终端**：同一台设备开多个终端标签。
- **地址簿**：RustDesk 账户的地址簿同步（需要先有账户系统；账户与登录已于 2026-09-08 删除）。
- **恢复不安全连接提示**：1.4.9 的「非端到端加密连接」对话框因 1.4.7 引擎缺少 `session_set_common` 而被删掉（`patches/lib_common.patch`）。引擎升级到 1.4.9 及以上后应恢复。

## 引擎与构建

- **升级引擎到与源码一致的版本**（目前源码 1.4.9、引擎 1.4.7）。需要同一次 RustDesk CI 构建产出的桥接文件和 `.so`，步骤见 [AGENTS.md](../AGENTS.md) 第 3 节。
- **构建不依赖本机代理**：`patches/android_gradle.patch` 把 Gradle 代理写死为 `127.0.0.1:7890`，换一台机器构建就会失败。应改为读取环境变量，或在没有代理时不设置。
- **只支持 arm64**：不打包其他 ABI。

## 待真机验证

目前每个版本只经过静态检查、单元测试和构建，没有在真机上逐项测试。需要验证：

- 整套手势（两种模式下的点按、拖动、长按拖动、双指平移/滚动/缩放、三四指点按）、手势灵敏度页、抬起即触发。
- 音量键各种绑定，特别是 v1.14.3 修复后的滚轮方向。
- 跟随远程光标、阻止对端输入。
- 后台自动进入画中画。
- 浅色主题（包括引擎弹窗）。
- 应用锁的防截屏和重新上锁。
- 多显示器切换。
- 声音、剪贴板开关。
