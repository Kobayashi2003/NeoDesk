# 代码结构

NeoDesk 是基于 RustDesk 预编译引擎的 Android 远程桌面**控制端**，界面与手势系统全部重写。仓库里不存放 RustDesk 源码：`rustdesk/` 是构建时由「上游源码 + `patches/` + `overlay/`」生成的目录，生成过程与修改规则见 [AGENTS.md](../AGENTS.md)。

## 分层

```
neodesk_core/          我们的 UI 与抽象端口（ports），不依赖引擎，可在 FakeCore 上独立运行
      ▲ 实现端口
overlay/lib/neodesk/   适配层：唯一允许调用 gFFI / bind.* 的我方代码
      ▲ 调用
上游 RustDesk + librustdesk.so
```

UI 只通过 `NeodeskCore`（`neodesk_core/lib/core/services/session_manager.dart`）访问引擎。给 UI 新增能力 = 给端口加方法，并在 `FakeCore` 和适配层各实现一次。
